# Canada PR Tracker — Rajasekaran Selvaraj

A personal Canada Permanent Residence journey tracker web application.

## Features
- Live countdown timers for key deadlines (H1B expiry, ECA expiry, work permit cap)
- CRS Score simulator — see how French/IELTS/PNP affect your score
- Interactive documents checklist (saved in browser)
- Priority action items with checkboxes
- PNP status board
- IELTS scores and French language tracker
- Personal notes (auto-saved in browser)
- Dark/Light mode

## How to Deploy for FREE (GitHub Pages)

### Step 1: Create a GitHub Account
- Go to [github.com](https://github.com) and sign up (free)

### Step 2: Create a New Repository
- Click "New repository"
- Name it: `canada-pr-tracker` (or any name you like)
- Set it to **Public**
- Click "Create repository"

### Step 3: Upload Files
- Click "uploading an existing file"
- Upload all 3 files: `index.html`, `style.css`, `app.js`
- Click "Commit changes"

### Step 4: Enable GitHub Pages
- Go to repository **Settings** → **Pages**
- Source: Deploy from a branch
- Branch: `main` → folder: `/ (root)`
- Click **Save**

### Step 5: Access Your Website
- Your site will be live at: `https://YOUR-USERNAME.github.io/canada-pr-tracker/`
- Accessible from anywhere — any browser, any device!

## Alternative Free Hosting Options

## Data Privacy
- All your notes and checkbox states are stored **locally in your browser** only
- No server, no database, no account login needed
- Your data stays on your device
